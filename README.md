# Gaslands-Car-Detector-Gate
A project for week 2 of Half Life!
It is going to be a gate for Gaslands that has starting lights and detects when cars have finished the race. It will detect the cars by using an ultrasonic sensor and will include LEDs and a buzzer as the actuators.
