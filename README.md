# Gaslands-Car-Detector-Gate
A project for week 2 of Half Life!
It is going to be a gate for Gaslands that has starting lights and detects when cars have finished the race. It will detect the cars by using an IR beam break sensor and will include LEDs and a buzzer as the actuators. I will be designing the majority of the project in Fusion360 but I will use TinkerCad to create barrels and props to make the environment feel right for the world it's set in.
